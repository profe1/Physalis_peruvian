# Physalis peruviana: agrupamiento de imágenes de hojas

Código del procedimiento de extracción de características y
agrupamiento de imágenes de hojas de Physalis peruviana.

## Cuaderno de ejecución

[Ejecutar en Google Colab](https://colab.research.google.com/drive/1e159he4YAJyWV__e9Xhb-rE6XjIaeZYl?usp=sharing)

## Imágenes

- [Imágenes de entrada](https://drive.google.com/drive/folders/1i2477pqzMzfWB1y9LQZlOYPFceOYiWYG?usp=sharing)
- [Resultados de agrupamiento](https://drive.google.com/drive/folders/1zdDal3URCkvyr85Hm5ZexN8EImH4E0Po?usp=sharing)

## Instrucciones

1. Abra el cuaderno en Google Colab y guarde una copia.
2. Añada un acceso directo de la carpeta de entrada a su “Mi unidad”.
3. Ejecute la celda que monta Google Drive.
4. Actualice IMAGE_PATH con la ruta de las imágenes en su unidad.
5. Configure OUTPUT_PATH en una carpeta propia para los resultados.
6. Ejecute las celdas en orden.

Las rutas de Google Drive deben adaptarse a la cuenta de cada usuario.
Compartir el cuaderno no concede acceso automático a las imágenes.

## Alcance

Este repositorio documenta el procedimiento de agrupamiento de hojas.
No constituye por sí solo el código completo del sistema de
clasificación de hojas, frutos y tallos.
